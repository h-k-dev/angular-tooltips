JS Anchor

The hkJsTooltip directive for every host that can not be an Interest Invoker — <span>, <div>, <img>, <input>, icons, component hosts. What the browser does for invokers is done here in JS, tippy-style: pointer and focus listeners, show/hide delays, keep-open while hovering the bubble, Escape and tap-outside to dismiss. Positioning is still 100% CSS Anchor Positioning, the popover is the same singleton, and the API is identical — only the engine differs.
