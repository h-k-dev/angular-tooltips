Theming

The singleton is styled only through --tt-* custom properties set on :root (or any ancestor of <body>). Anything you leave unset falls back to the Angular Material tooltip tokens, then the --mat-sys-* system tokens, then a built-in default — with a Material theme present the tooltip matches it out of the box. Both engines render the same popover, so one theme covers both.
