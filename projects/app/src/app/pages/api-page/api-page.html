API

Two directives, one interface. Pick the directive by host — hkTooltip for elements that can be interest invokers, hkJsTooltip for everything else — and everything after that is identical: the same inputs, the same methods, the same singleton. See it live on Tooltips.

HkTooltipCache

Root-provided TTL + LRU cache for async tooltip content, meant for a resource() loader inside a template. The promise is cached, so concurrent hovers share one request. Add it to a component's providers to scope its lifetime to that component.
